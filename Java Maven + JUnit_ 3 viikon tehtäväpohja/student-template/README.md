# Java Programming: weekly exercises (student template)

This is a Maven multi-module project with **Java 21** and **JUnit 5**. Implement the `TODO` methods in each week's `src/main/java` directory. Do not change method signatures or the supplied tests.

## Requirements
- JDK 21, Maven 3.9+, Git, GitHub account

## Weekly work
1. Clone your **own private** repository (`git clone <your-repository-url>`).
2. Open the project root in IntelliJ IDEA or VS Code.
3. Read `week01/README.md`, etc., and implement the methods.
4. Run `mvn -f week01/pom.xml test` (change week number as needed).
5. Run `mvn test` at project root to test all weeks.
6. `git add . && git commit -m "Complete week 01" && git push`.
7. Check the **Actions** tab in your repository. Green = all supplied tests passed; it does not guarantee full credit.

## Submission
Your instructor determines the deadline and which commit counts. Submit your repository URL in Moodle if instructed. Keep your repository private and grant the instructor access.

## Notes
- The starter methods intentionally return placeholder values, so tests initially fail.
- Do not put secrets or personal information in the repository.
- Additional instructor-only tests may be used for final grading.
