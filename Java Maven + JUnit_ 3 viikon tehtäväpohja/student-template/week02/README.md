# Week 02: Conditions and loops

## Assignment
Implement isEven, sumTo and maxOfThree in NumberTools.java.

Keep the public method names and signatures unchanged. Implement general solutions, not hard-coded example results.

## Test locally
From the repository root:

```bash
mvn -f week02/pom.xml test
```

After the tests pass, commit and push your code to your private GitHub repository. The instructor may run additional tests with different input values.
